1. Safety guard for automatic GitHub pushes
The watch workflow can accidentally commit sensitive files. Add:

Dry-run mode
Protected file list for .env, tokens, private keys, database files, and local exports
Secret scanning before commit
Show the files that will be pushed
Optional confirmation before the first push
Maximum file-size protection
This is the most important improvement.

2. Real download progress
The current progress messages show stages, but not exact percentage. Improve it with:

Current artifact name
Downloaded MB / total MB
Percentage
Overall progress across all artifacts and logs
Retry status
Cancel button
This requires changing downloads into background jobs instead of keeping the browser request open.
