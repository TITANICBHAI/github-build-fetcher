Why BuildFetchr exists

A small tool for the moment after a build finishes.

Build outputs are often the last mile of a development workflow. The run completed, the artifact exists, but finding the right run, checking its status, downloading logs, and moving a file can require several screens or another command-line tool.

BuildFetchr focuses on that narrow gap. It gives a local browser interface for inspecting recent runs, selecting exactly one build, and creating a verifiable export. It also makes write operations explicit rather than hiding them behind automation.

The project is intentionally independent. It uses GitHub APIs when requested, but it is not GitHub software and does not try to replace GitHub’s own products, policies, or security controls.

Use responsibly: Keep credentials out of source code, use least privilege, and maintain separate backups for anything important.
