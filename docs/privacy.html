Privacy Policy

This policy describes the standalone BuildFetchr software and the informational pages in this folder. This is general product information, not legal advice.

1. Local application

BuildFetchr runs a local server on your device. By default, the project does not operate a central analytics or advertising system and does not intentionally collect personal information from the local application.

2. Information you choose to provide

When you use a feature, you may provide a repository URL, a personal access token, OAuth configuration, file contents, branch names, commit messages, or pull-request text. The application uses that information to make the request you selected. Tokens entered in the form are intended to remain in process memory and are not written into exports by the application, but you remain responsible for your device and environment.

3. Third-party services

Requests to GitHub are governed by GitHub’s terms and privacy policy. Your browser, operating system, network provider, GitHub, and any configured hosting service may create their own logs or process data independently of this project.

4. Local storage and files

The browser may store the acceptance of the app notice. The application can save exports and settings where you request; inspect and delete those files as needed.

5. Security

No software can promise absolute security. Never share tokens in source code, screenshots, issues, chat, or public repositories. Use least-privilege credentials and revoke credentials if exposure is suspected.

6. Changes

This policy may change with future versions. Continued use after an update means you should review the current policy.
