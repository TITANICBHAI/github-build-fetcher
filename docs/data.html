Plain-language overview

Data collection

BuildFetchr is designed to run locally. Here is what it does and does not collect by default.

Sent to GitHub

Repository links, selected run or artifact requests, and credentials you provide are sent to GitHub endpoints to perform the requested operation.

Kept locally

Downloaded exports, temporary files, session state, and optional saved repository settings may exist on your device according to your choices.

Not collected by us

The project does not include an analytics service, advertising tracker, hosted telemetry collector, or credential database.

Your responsibilities

  • Use only accounts and repositories you are authorized to access.
  • Protect environment variables, tokens, downloaded artifacts, logs, and backups.
  • Review GitHub permissions and revoke tokens through GitHub when they are no longer needed.
  • Delete local exports and browser data when appropriate for your security requirements.

Network providers, GitHub, operating systems, browsers, and hosting platforms may process data under their own policies. See the Privacy Policy.
