BuildFetchr helps you inspect workflow runs, download artifacts and logs, and move files through GitHub’s APIs without installing GitHub CLI or extra Python packages.

Inspect

See workflows, runs, branches, events, statuses, commits, and access details in one local browser page.

Fetch

Download all artifacts, individual artifacts, and optional logs into verified ZIP exports with checksums.

Move

Push a selected file, create a branch, or open a pull request with explicit actions and safety checks.

Built for local control

The desktop executable runs a local server and opens your browser. Credentials are supplied at runtime and are not bundled with the application. BuildFetchr does not replace GitHub, Git, or your organization’s backup and security processes.
