What it does

Features

A focused local utility for finding and transporting GitHub-hosted build outputs.

Run discovery

Load workflows and recent runs, then filter by branch, workflow name, status, event, and date.

Verified exports

Download artifacts and logs in a ZIP with run metadata and SHA-256 checksums.

Access diagnostics

Check repository visibility, rate limits, token presence, scopes, and permissions.

Safe file push

Scan staged files for credentials, protected files, oversized files, and accidental local data before pushing.

Branch and PR tools

Create a branch, commit a file, and open a pull request through explicit user actions.

Portable operation

Use the Windows portable package or installable package. The app needs no separate Python installation.

Limit: Features depend on GitHub API availability, repository permissions, network access, and your own configuration. Do not treat the app as a backup, compliance, or disaster-recovery system.
